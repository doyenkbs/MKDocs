# Welcome to My Homelab Wiki

This site documents the infrastructure, services, and projects that make up my homelab. My goal is to automate, experiment, and self-host a range of technologies for learning, reliability, and privacy.

---

## What is a Homelab?

A homelab is a self-managed environment—typically located at home—where I can experiment with new hardware and software, practice skills, and host essential personal services. Homelabs support learning, allow for hands-on experience with new tech, and minimize dependence on third-party cloud providers.

---

## Homelab Goals

- Automate provisioning, upgrades, and monitoring of services (Infrastructure as Code and GitOps)[1]
- Self-host data storage, media, and applications
- Enhance security, privacy, and control over my digital life
- Learn and practice on industry-standard platforms and tools
- Maintain a robust and resilient network and backup strategy
- Experiment with virtualization, containerization, and orchestration technologies

---

## Core Technologies

- **Compute:** Virtual machines (e.g., Proxmox, KVM), containers (Docker, Podman), and Kubernetes clusters[3][1]
- **Networking:** VLANs, firewalling, VPN access (WireGuard), and DNS filtering
- **Storage:** NAS (e.g., TrueNAS), cloud sync, and automated backups
- **Automation:** Infrastructure as Code tools like Ansible, Terraform, or Nix[1]
- **Monitoring & Logging:** Prometheus, Grafana, and centralized logging
- **Self-Hosted Services:** Media servers, home automation, databases, CI/CD pipelines

## Directory Structure

- **Hardware:** Server specs, network layout, rack equipment
