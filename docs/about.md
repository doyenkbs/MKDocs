# About This Site
</div>

## <span style="color:#009688;">Why This Site Exists

I'm Christian Kaba, and this is where I document my self-hosted home lab —
partly for myself, partly for anyone else building something similar.

I started keeping notes because I kept solving the same problems twice: forgetting
a config flag, re-discovering a fix I'd already found six months earlier, or
rebuilding something from scratch after a hardware change. This site is the
result — a running record of what I've set up, how, and why, written as I go.

## <span style="color:#009688;">What's Covered Here

- **Virtualization** — Proxmox VE and VMware ESXi setups, from install to ongoing config
- **Applications & Integrations** — self-hosted apps like Nextcloud, Bookstack, and Paperless-NGX, tied together with Authentik SSO
- **Core Services** — networking and access layer: Cloudflare Tunnels, Home Assistant, OpenVPN
- **Microsoft Lab** — a full SCCM/MECM lab build on Hyper-V, from domain controller to software updates
- **Tanium** — administration notes and packaging guides

## <span style="color:#009688;">How It's Organized

Pages are grouped by function rather than by the order I built things — so if
you're looking for how a specific piece fits together, start from whichever
section matches what you're trying to do, not necessarily the nav order.
