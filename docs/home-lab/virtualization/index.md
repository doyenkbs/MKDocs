# **Containers & Virtualization**

This section covers container and virtualization platforms that form the backbone of your home lab infrastructure.

Included topics:

- **Proxmox VE** – open-source server virtualization management
- **VMWare ESXi** – enterprise-grade hypervisor
- **Docker** – containerization platform for lightweight, scalable application deployment

Learn how to install, configure, and manage your virtual machines and containers for optimal performance and flexibility.
