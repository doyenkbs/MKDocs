# **<span style="color:#F38020;">Containers & Virtualization</span>**

This section covers container and virtualization platforms that form the backbone of your home lab infrastructure.

Included topics:

- **<span style="color:#F38020;">Proxmox VE</span>** – open-source server virtualization management
- **<span style="color:#F38020;">VMWare ESXi</span>** – enterprise-grade hypervisor
- **<span style="color:#F38020;">Docker</span>** – containerization platform for lightweight, scalable application deployment

Learn how to install, configure, and manage your virtual machines and containers for optimal performance and flexibility.
