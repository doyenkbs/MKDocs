# **Home Lab**

Welcome to the Home Lab documentation hub—a curated collection of guides and resources detailing the deployment and management of self-hosted services and infrastructure within my personal lab environment. This section covers a variety of key applications and tools, from infrastructure automation and containerization platforms to specialized service deployments.

Here you will find step-by-step, practical instructions for setting up popular self-hosted solutions, including:

- **Audiobookshelf**: Manage and stream audiobooks and podcasts using an LXC container on Proxmox VE.
- **Authentik**: Centralized authentication and single sign-on.
- **BookStack**: A knowledge base and wiki platform running on Ubuntu with Nginx, PHP, and MariaDB.
- **Cloudflare Tunnel**: Secure access to internal services without firewall exposure.
- **Nextcloud**: Private cloud for file sync, sharing, and collaboration.
- **OpenVPN**: Secure remote access VPN with encryption.
- **PairDrop**: A secure, local file sharing service deployed easily on Proxmox using helper scripts.
- **aperless-ngx**: A document management system oriented around scanned files, deployed via Docker Compose.
- **SCCM Server**: Windows endpoint management and deployment.
- **Snipe-IT**: An IT asset management system installed on Ubuntu with Nginx, MariaDB, and PHP.

Each guide is designed to provide you with clear, tested commands and configuration examples to streamline your setup and get you running quickly. Moreover, the documentation includes best practices around Docker, container management, and network configurations to help secure your infrastructure and maximize privacy.

Use this section as your go-to resource for managing a versatile and modern homelab—the perfect sandbox to learn, experiment, and control your digital environment end-to-end.
