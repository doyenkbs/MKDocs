# **<span style="color:teal;">SCCM Lab Setup Guide</span>**

In this project, I established a comprehensive **<span style="color:teal;">SCCM (System Center Configuration Manager)</span>** lab environment to facilitate advanced software deployment, management, and reporting. The setup involved configuring SCCM on either **Microsoft Azure**, a **local machine using Proxmox VMs** or **Hyper-v**, ensuring a robust and scalable test environment.

---

## **Key Tasks Included**

- **<span style="color:teal;">Deployment and Configuration:** Installed and configured SCCM, deploying essential software packages, applications, Office 365, PowerShell scripts, and Windows updates.  
- **<span style="color:teal;">Infrastructure Setup:** Created boundary groups, users, and device collections to streamline management and deployment processes.  
- **<span style="color:teal;">Reporting and Analysis:** Developed custom reports and queries, utilizing SQL Management Studio for in-depth reporting and analysis.  
- **<span style="color:teal;">Advanced Configurations:** Created task sequences to automate deployment tasks and implemented PXE boot to facilitate network-based installations.  

This project demonstrated my ability to design and implement a scalable SCCM environment, leveraging both cloud and local resources to enhance software management and deployment capabilities.

---

## **Lab Architecture**

- **<span style="color:teal;">Domain Server:** DC, DNS, DHCP  
- **<span style="color:teal;">MECM/SCCM Server:** Database, MP (Management Point), DP (Distribution Point), SMS Provider, and SCP (Service Connection Provider)  
- **<span style="color:teal;">Client PC:** Windows 10 or Windows 11
